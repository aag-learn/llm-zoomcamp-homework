## `llm-zoomcamp` homework (2026 cohort)

To run the jupyter notebook, clone the respository

```shell
> git clone https://github.com/aag-learn/llm-zoomcamp-homework.git
```

install the prerequisites:

```shell
> mise install
```

install the `uv` dependencies:

```shell
> uv sync
```

`cd` into the module folder, for example module 1:

```shell
> cd module-1
```

run the notebook:

```shell
> uv run jupyter notebook
```

and point the browser to the urls indicated in the terminal. You can also run the notebook in VSCode or any other IDE that supports jupyter notebooks.
